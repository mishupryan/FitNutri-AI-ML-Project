# FitNutri AI – Machine Learning Project

## Project Overview

FitNutri AI is an academic project focused on applying Machine Learning and Artificial Intelligence to nutrition and food-related data. The project explores how machine learning techniques can be used to analyze food information and support better nutritional decisions.

This repository contains the project presentation, project report, laboratory files of all group members, and the project source code.

## Project Objectives

- Apply Machine Learning concepts to food and nutrition data.
- Explore the use of Artificial Neural Networks and other ML algorithms.
- Analyze nutritional information and food-related features.
- Understand model training, testing, and performance evaluation.
- Compare the results of different machine learning approaches.
